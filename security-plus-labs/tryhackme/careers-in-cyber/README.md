## Overview
An overview of the different career paths in cybersecurity, from offensive roles (breaking into systems) to defensive roles (protecting organizations).

## Task 1: Introduction
Cybersecurity has many career paths, and you don't need a specific background to start — curiosity and problem-solving skills go a long way.

**Why get a career in cyber:**
- **High demand:** over 3.5 million unfilled roles
- **Strong salaries:** competitive pay even at entry level
- **Constant learning:** the field evolves fast

**Question:** How many unfilled cyber positions are there?
**Answer:** `3.5 million`

## Task 2: Security Analysis
Security analysts are the digital defenders of an organization, sitting on the **blue team**. They monitor, investigate, and respond to activity on devices and networks, piecing together potential security incidents (**alerts**) to decide if action is needed.

**Example scenario:** An employee based in London suddenly logs in from another country — requires investigation to confirm legitimacy.

**A typical day involves:**
- Monitoring activity on devices/network
- Investigating unusual activity (e.g., strange logins)
- Piecing together what happened, when, and how
- Working with other teams to improve defences

**Progression:** Broad entry point into defensive security → threat hunting, incident response, or malware analysis.

**Question:** Security analysts play a significant role in an organisation's ______?
**Answer:** `defence`

## Task 3: Security Engineering
Security Engineers build and maintain the systems and processes that protect an organization — the "architects" of cybersecurity. Example: maintaining an **Intrusion Detection System (IDS)**, which acts like a security camera, using rules and intelligence to detect/prevent attacks.

**A typical day involves:**
- Designing and maintaining security systems
- Keeping up with the latest hacker techniques
- Documenting processes and procedures
- Assessing risk and protecting against vulnerabilities

**Progression:** Already specialized → can go deeper into application security or cloud security. Skills transfer well into offensive security too.

**Question:** What is the name for the type of device that a Security Engineer would be responsible for maintaining?
**Answer:** `Intrusion Detection System`

## Task 4: Penetration Testing
Also called "pentesting" or "ethical hacking." A penetration tester checks how secure a company's systems/software are by safely trying to break into them, under a formal agreement with the company (called an **engagement**).

**A typical day involves:**
- Testing security of systems, networks, and websites
- Performing security assessments, audits, and policy analysis
- Analyzing results and creating reports advising on prevention

**Progression:** Strong start for offensive security → network/web app testing → **red teaming** (simulating full-scale, long-term attacks, sometimes including physical intrusion).

**Question:** What process do penetration testers follow when testing an organisation for weaknesses?
**Answer:** `engagement`
