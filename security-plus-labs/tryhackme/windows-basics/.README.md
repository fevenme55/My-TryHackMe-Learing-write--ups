## Task 3 — Configuring and Securing Windows

### Updating Your Applications

Keeping your operating system and applications up to date is an important part of maintaining a secure and stable system. Updates often include security patches, performance updates, and bug fixes.

**Windows Updates**
Windows includes a built-in update tool called **Windows Update**, which keeps the OS and some native applications and security features up to date. It's accessed through the Settings app and may install updates automatically, depending on configuration.

**Updating Applications**
Application updates work differently depending on how the software is installed:
- Built-in applications may update automatically in the background
- Third-party applications often include their own update mechanisms
- Some applications prompt you to update upon launch
- Some require you to check for updates or download a new installer manually

### Installing Applications

Think of installing apps like going through an airport: there's a curated, pre-screened route and an open, direct route.

1. **Microsoft Store** — Provides a curated and safe option for installing apps to Windows (like a TSA PreCheck lane: vetted ahead of time). Not available by default on Windows Server.
2. **From the Internet** — In many environments, apps are installed by downloading an installer directly from a trusted vendor's website (the regular check-in line — you go straight to the source, but it's on you to confirm the vendor is legitimate). These usually come as an `.exe` or `.msi` file and guide the user through installation.

### Uninstalling Applications

There are multiple ways to uninstall programs in a Windows environment:
- Using the Microsoft Store for installed applications
- "Add or remove programs" feature in system settings
- "Uninstall a program" section of the Control Panel
- Using an application's built-in uninstaller

### Diving Into Settings

Beyond the "About your PC" section explored earlier, Windows offers two primary ways to modify the environment:

1. **Windows Settings** — A modern, centralized location for configuring system, device, personalization, and security settings
2. **Control Panel** — A legacy management interface that provides access to older system configuration tools still required for specific administrative tasks

Both let you manage system preferences including display and audio settings, user accounts, apps, network options, accessibility features, and security configurations.

### The Task Manager

**Task Manager** is a built-in Windows tool for monitoring what's happening on a system in real time — running applications, background processes, and performance metrics like CPU and memory usage.

Task Manager has five tabs:
1. **Processes** — Currently running apps and background processes, and their resource usage
2. **Performance** — Graphs and statistics for system resources such as CPU, memory, and network
3. **Users** — Currently logged-in users and their used resources
4. **Details** — A more technical view of running processes, including process IDs (PIDs)
5. **Services** — Windows services and their current status (running or stopped)

### Native Windows Security

Windows offers built-in security tools, enabled by default, designed to protect a system from malware, insecure applications, and unauthorized network access.

**Windows Security** is the central dashboard for managing Windows' built-in protection measures, divided into four main sections:
- **Virus & threat protection** — Detects and removes malicious software using real-time protection and customizable scans
- **Firewall & network protection** — Controls incoming and outgoing network traffic to help prevent unauthorized access
- **App & browser control** — Protects users from potentially unsafe apps, files, and websites
- **Device security** — Provides hardware-based protections that help secure the system

**Hands-On: Running a Custom Scan**
1. Opened Windows Security via the Desktop shortcut
2. Selected the Virus & Threat protection section
3. Chose Scan options → Custom scan → Scan now
4. Selected the `TryHatMe Onboarding` folder as the scan target
5. The scan detected a safe EICAR test file (`Virus:DOS/EICAR_Test_File`), flagged as Severe, with Quarantine selected as the action

This demonstrated how Windows is capable of scanning for and detecting threats, using a harmless industry-standard test file (EICAR) rather than real malware.

### Windows Defender Firewall

**Windows Defender Firewall** is a built-in firewall that protects a computer from unauthorized network traffic. It monitors network connections and applies rules determining whether connections are allowed or denied. It operates on different network profiles:

- **Domain** — Used when a system is connected to an organization's domain network
- **Private** — Intended for trusted networks, such as a home or lab environment
- **Public** — Used for untrusted networks, such as public WiFi

In the **Advanced settings**, you can view:
1. An overview of the firewall's inbound, outbound, and connection security rules
2. A detailed view of each rule, including name, group, network profile, status, and action
3. The ability to create new rules or filter the current view

## Summary / Takeaways

- Windows gives you two parallel paths to configure a system — the modern **Windows Settings** app and the legacy **Control Panel** — and knowing both matters because many environments (especially servers) still rely on older tools.
- **Task Manager** is a first-stop triage tool: Processes/Performance for resource usage, Users for who's logged in, Details for PIDs, and Services for what's running in the background — all directly useful for initial investigation in a SOC context.
- **Windows Security** bundles antivirus, firewall, app/browser control, and device security into one dashboard; running a custom scan against a known-safe EICAR test file is the standard, harmless way to verify detection tooling is working.
- **Windows Defender Firewall** rules are scoped by network profile (Domain/Private/Public), reflecting that trust level should change based on the network a device is connected to.
- App installation methods matter for attack surface: Microsoft Store apps are curated/vetted, while installers pulled directly from vendor sites (`.exe`/`.msi`) depend entirely on the source being trustworthy — a distinction relevant to software supply-chain awareness.
